Legend and caveats
What an escape is
  • An escape is a test main failed after the landing.
  • A conviction count is not a regression count: one regression convicts again on later pull requests tripping it.
  • A floor: only landings pinned from a pull request title, only same-configuration runs, {{ window_days }} days either side.
  • Undecided convictions are counted above, not dropped.
The three count pairs
  • Before: failures of runs in the {{ window_days }} days before.
  • Rate increase: Newcombe lower bound on two Wilson intervals at alpha {{ '%.2f' | format(significance_alpha) }}, not the rate.
  • STRONG: bound above zero, a rise beyond chance, not the old 50% run share.
  • UNPROVEN: at or below zero, no rise shown, not no failures.
  • Current damage: recent_failed of recent_runs, last {{ currency_days }} days.
  • Blank is no answer, not zero: nobody asked, or main ran it no times.
  • recent_runs is a floor (a per-response-group limit), not clamped to the landing.
