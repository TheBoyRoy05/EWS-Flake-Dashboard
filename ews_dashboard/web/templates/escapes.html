How an escape is decided, and what this page cannot see

Every other number on this dashboard is a floor, because main does not contain the change: a test that is reliable on main and was genuinely broken by the change cannot be told apart from one that flaked during the build. Once the change lands that distinction exists, so this page is the only place a conviction can be checked rather than qualified. A conviction is called an escape when main failed the test unexpectedly in {{ failure_pct }}% or more of the runs over the {{ window_days }} days after the landing, having failed it in less than that share of the runs over the {{ window_days }} days before it. Every other unexpected failure main showed is main's own, whether it flaked after the landing or was already failing before it, and counts as a conviction main agreed with rather than one it answered nothing about.

This too is a floor. It sees only pull requests whose landing could be pinned down from their title, only tests some bot runs on main in the same configuration, and only the window either side of the landing; a test main already lists as failing is not counted at all. The convictions it could not decide are counted above rather than dropped.
